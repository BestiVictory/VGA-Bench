# AI生成视频评价任务说明
任务目标：
你将接收一段AI生成视频、一段用于生成该视频的prompt、1到6个单选题以及对应的选项。请你进行 **单选题作答**。
输出必须为严格的 JSON 数据格式（详见下文输出格式）。

========================
一、分类体系与定义
========================

问题分为三大类，一致性问题、真实性问题、基础质量问题，对应选项为该问题的分数以及对分数的解释

【1. 一致性问题】
问题会针对视频和prompt中的某些元素提问，提问视频是否与prompt提及的对应元素足够一致。
- 一致性为概念性问题，区别于真实性，只要视频中对应元素符合prompt中的描述，即为足够一致。
- 一致性同时涉及空间和时间，只有该元素在整个视频过程中都一致才为足够一致。
---

【2. 真实性问题】
问题会针对视频和某些元素提问，提问视频中相关元素是否足够真实。
- 真实性区别与一致性问题，与prompt内容无关，你应当只分析视频与问题，而真实性的标准是现实世界。
- 真实性问题不止涉及静态语义如物体真实性还涉及动态语义如行为、物理现象。
---

【3. 基础质量问题】
问题只与生成视频本身性质有关，与prompt或视频具体内容无关。主要问题涉及视频清晰度、曝光等视频性质或时序一致性等生成性质。
- 基础质量问题应结合整个视频综合评价。
---


========================
二、输出格式（Schema）
========================

每个视频输出一个 JSON 对象，字段如下：
{
    "q1": "string",
    "q2": "string",
    "q3": "string",
    "q4": "string",
    "q5": "string",
    "q6": "string",
}

输出要求：
- 返回 JSON 数据，每个元素为上述对象。
- 每个视频包含的问题数量不同，3个问题则只返回q1、q2、q3。
- 不包含额外说明、文字或注释。
- 所有value必须使用选项提供的分数。
- 若无法判断，请置空（""）并降低 confidence。

========================
三、输出示例
========================

{
    "q1": "3：完全一致（描述周期性动作时应当整个视频都一致，一次性动作应当完成）",
    "q2": "4：大部分内容真实",
    "q3": "2：产生轻微扭曲",
},
{
    ...
}



请仅输出 JSON 结果，不要添加额外文字解释。
